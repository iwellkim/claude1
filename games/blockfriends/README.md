# 🌸 블록 친구들의 모험

초등학교 1학년(7세)을 위한 **마인크래프트 스타일 어드벤처 RPG**.
파일 하나(`index.html`)만 브라우저로 열면 바로 실행됩니다. 설치·인터넷 연결 필요 없음.

> 공식 마인크래프트가 아니라 그 스타일을 따른 팬 게임입니다.
> 공식 로고·에셋은 사용하지 않았고, 캐릭터 그림은 전부 직접 그린 픽셀 아트입니다.

## 실행

```bash
# 그냥 파일을 더블클릭하거나
open games/blockfriends/index.html

# 또는 로컬 서버로
python3 -m http.server 8000
# → http://localhost:8000/games/blockfriends/index.html
```

## 7세 눈높이로 맞춘 것

| 항목 | 내용 |
| --- | --- |
| 글자 | 아주 큰 글씨, 짧은 한 문장, 쉬운 낱말만 |
| 읽어주기 | 🔊 버튼을 켜면 브라우저 음성이 한국어로 읽어 줌 (아직 한글이 서툰 아이용) |
| 조사 | 받침에 따라 을/를·와/과·이/가 자동 선택 ("아기 양를" 같은 말이 안 나옴) |
| 줄바꿈 | `word-break: keep-all` 로 어절 중간에서 끊기지 않음 |
| 버튼 | 화면당 2~3개, 손가락으로 누르기 쉬운 크기 |
| 실패 | **없음.** 하트가 다 닳으면 "잠깐 쉬었어요!" 하고 가득 채워 줌 (진행·아이템 손실 0) |
| 무서움 | 어두운 곳·공격적인 몹 없음. 모두 웃는 얼굴에 볼터치 |

## 놀이 방법

1. **친구 만나기** — 톡톡 놀아 주면 친구가 됩니다. 모은 친구는 화면 아래에 줄줄이 따라다녀요.
2. **블록 캐기** — 블록을 두 번씩 누르면 깨지고 보석이 나옵니다.
3. **선물 상자** — 밥과 보석을 받습니다.

보석을 모으면 무기가 저절로 좋아집니다.

```
나무 막대 → 나무 검 → 돌 검 → 철 검 → 다이아 검 → ⭐ 별 검
   0개        3개       8개      16개      26개        38개
```

## 만든 방식

- 의존성 0. HTML 파일 하나에 CSS·JS 전부 들어 있음
- 캐릭터는 문자열 픽셀맵을 캔버스에 찍어 그림 (`SPR`), 블록 텍스처는 노이즈로 즉석 생성
- 효과음은 WebAudio 합성음, 음성은 `SpeechSynthesis` — 외부 파일 요청 없음
- 진행 상황은 `localStorage` 에 자동 저장 → 껐다 켜도 "이어 하기"
- `prefers-reduced-motion` 존중, 키보드 포커스 표시 있음
