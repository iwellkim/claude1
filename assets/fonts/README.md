# 한글 폰트 디렉토리

이 디렉토리에 `.ttf` 또는 `.otf` 파일을 두면 서버 시작 시
matplotlib 에 자동으로 등록되어 차트에서 한글이 깨지지 않습니다.

추천 무료 폰트:
- NanumGothic (https://hangeul.naver.com/2017/nanum)
- Noto Sans KR (https://fonts.google.com/noto/specimen/Noto+Sans+KR)

시스템에 이미 한글 폰트(맑은 고딕, AppleGothic, NanumGothic, Noto Sans CJK KR 등)가
설치되어 있다면 이 디렉토리는 비워 두셔도 됩니다.
